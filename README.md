# Java Core Practice & Programs

Welcome to the **Java** repository! This project contains a structured collection of core Java concepts, hands-on practice programs, control structures, object-oriented programming (OOP) demonstrations, custom exception handling, and file I/O operations.

---

## 📌 Repository Overview

This repository is organized to cover basic to intermediate Java topics:

* **Basic Concepts & Syntax:** Data types, variables, arithmetic operations, and relational operators.
* **Control Flow Statements:** Decision-making (`if-else`, `switch-case`) and loops (`for`, `while`).
* **Core Logic Programs:** Armstrong numbers, prime check, palindrome, power calculations, and leap year validation.
* **Object-Oriented Programming (OOP):** Classes, constructors, inheritance, polymorphism, abstraction, and encapsulation.
* **Exception Handling:** Built-in exception handling, `throw`, `throws`, and custom user-defined exceptions (e.g., `LowBalanceException`, `PlacementException`).
* **File Handling & I/O:** Reading, writing, appending, and deleting files using `BufferedReader`, `FileWriter`, and built-in file tools.
